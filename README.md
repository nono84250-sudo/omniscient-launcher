# Omniscient Launcher — Releases

Ce dépôt héberge uniquement les binaires publiés du launcher Omniscient
(installeur Windows web `nsis-web`, futurs builds macOS/Linux). Il ne
contient aucun code source — le développement se fait dans le dépôt privé
`mchub`.

Télécharger la dernière version : voir l'onglet [Releases](../../releases),
ou directement depuis la page [Download](https://omniscient-theta.vercel.app/download)
du site.
